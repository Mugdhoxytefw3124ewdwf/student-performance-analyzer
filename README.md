# student-performance-analyzer
Subject : A js foundational project.
A beginner JavaScript project built to practice:

- Variables
- Arrays
- Objects
- Nested data structures
- Loops
- Conditional statements
- Functions
- Finding the highest value
- Basic debugging and problem solving

The program analyzes student marks, calculates averages,
determines pass/fail status, and identifies the top-performing student.

Built with vanilla JavaScript.
