# Student Performance Analyzer

**Subject:** A JavaScript foundational project

A beginner-friendly JavaScript project built to practice and understand fundamental JavaScript concepts.

### For Beginners

You can use this project as a simple tutorial or reference if you are a beginner learning JavaScript fundamentals. The code focuses on core concepts rather than advanced methods, making it easier to follow and understand how each part works.

### Concepts Practiced

* Variables
* Arrays
* Objects
* Nested data structures
* Loops
* Conditional statements
* Functions
* Finding the highest value
* Basic debugging
* Problem-solving

### What the Program Does

The program analyzes student marks and:

* Calculates each student's average
* Determines whether the student passed or failed
* Identifies the student with the highest average
* Displays the results in the console

### Purpose

This project was created to strengthen my understanding of JavaScript fundamentals through practical problem-solving and hands-on coding.

**Built with vanilla JavaScript.**
